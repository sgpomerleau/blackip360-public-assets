# Images publiques Black IP 360

Ce dépôt héberge des images de marque destinées à être affichées publiquement
(logo, badges de certification, etc.), utilisées dans des courriels, des
signatures Outlook, ou d'autres endroits où une image doit être accessible
via une URL publique.

**Règle importante : ne jamais y mettre autre chose que des images déjà
destinées à être vues publiquement.** Aucune donnée client, capture d'écran
interne ou document — uniquement du matériel de marque.

## Utilisation

Chaque image est accessible via son URL brute GitHub :

```
https://raw.githubusercontent.com/sgpomerleau/blackip360-public-assets/main/<chemin>
```

Exemple — logo (version blanche, pour fonds sombres) :
```
https://raw.githubusercontent.com/sgpomerleau/blackip360-public-assets/main/logo/bip360-blanc.png
```
